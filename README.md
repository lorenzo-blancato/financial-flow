## 🇬🇧 English

### 📌 About the Project
**Financial Flow** is a minimal, dark-themed Progressive Web App (PWA) designed for quick, friction-free daily expense and income logging directly from smartphones (iOS & Android). 

This project was created as an **AI-assisted experiment** exploring the combination of modern artificial intelligence and GitHub ecosystem tools to build fully functional web applications. 

### 💡 Purpose & Workflow
While full-featured Excel workbooks offer rich styling, inter-sheet dynamic formulas, and native charts, entering expenses into large spreadsheets on a mobile device can be slow and cumbersome. **Financial Flow** solves this by acting as a fast mobile entry companion:
1. **Daily Logging**: Track incomes and expenses instantly on the go with custom categories (`Spesa`, `Cura Personale`, `Casa`, `Trasporti`, `Palestra`, `Cena Fuori`, `Uscite`, `Svapo & Terea`, etc.).
2. **Local Storage**: All records persist locally on the device (`localStorage`) without requiring external databases or user registration.
3. **Excel Export**: Export saved transactions to a structured `.xlsx` spreadsheet via SheetJS, making it seamless to copy data into an advanced master Excel template for deep financial analysis.

### 🛠️ Built With
- **HTML5, CSS3, Vanilla JavaScript**
- **Chart.js** for mobile-first interactive data visualizations
- **SheetJS (`xlsx`)** for Excel import and export capabilities
- **GitHub Pages** for free, static web hosting
- **Generated with AI**

## 🇮🇹 Italiano

### 📌 Informazioni sul Progetto
**Financial Flow** è una Progressive Web App (PWA) dal design *dark minimal*, sviluppata per registrare in modo rapido e senza frizioni entrate e uscite quotidiane direttamente dallo smartphone (iOS e Android).

Questo progetto nasce come un **esperimento pratico sviluppato con l'ausilio dell'Intelligenza Artificiale**, esplorando le potenzialità delle tecnologie web moderne e dell'ecosistema GitHub per la creazione di web app funzionali e pronte all'uso.

### 💡 Scopo del Progetto e Workflow
I fogli di calcolo Excel avanzati offrono una grafica curata, formule interattive tra fogli e grafici nativi, ma l'inserimento quotidiano degli scontrini da smartphone può risultare poco agevole. **Financial Flow** nasce come estensione mobile del foglio di calcolo:
1. **Inserimento Rapido**: Registra al volo spese ed entrate divisi per sottocategorie personalizzate (`Spesa`, `Cura Personale`, `Casa`, `Trasporti`, `Palestra`, `Cena Fuori`, `Uscite`, `Svapo & Terea`, ecc.).
2. **Salvataggio Locale**: I dati vengono salvati direttamente nella memoria del dispositivo (`localStorage`), garantendo massima privacy senza bisogno di server o registrazione.
3. **Esportazione Excel**: Genera un file `.xlsx` compatibile per trasferire ed integrare con facilità i movimenti all'interno del file Excel master.

### 🛠️ Tecnologie Utilizzate
- **HTML5, CSS3, JavaScript Vanilla**
- **Chart.js** per la visualizzazione dei grafici e delle statistiche
- **SheetJS (`xlsx`)** per l'importazione ed esportazione dei file Excel
- **GitHub Pages** per l'hosting statico gratuito
- **Sviluppato con il supporto dell'Intelligenza Artificiale**
